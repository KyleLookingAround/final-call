# Brief: Cache Playwright's Chromium in CI (the first half of runbook experiment [B])

The coordinator's brief for a CI speed-up the owner chose on 27 Sep 2026, brought forward because about ten sessions are pushing at once. It makes CI faster without changing what it checks. No game code.

## Goal and what it may touch

- In `checks.yml`, `balance.yml` and `parts.yml`, cache Playwright's browsers (`~/.cache/ms-playwright`), keyed on the pinned Playwright version from `package-lock.json`. Skip the download on a cache hit. Keep the system libraries Chromium needs installed either way, the fastest way that works (for example `npx playwright install-deps chromium`, or `install --with-deps` only on a miss). Look for other plain wins in the setup steps too, but don't change which checks or bot runs happen, their options or their pass marks.
- Measure it: the setup time and total time of the `check` job and one `bot` job, before (from recent runs on `main`'s PRs) and after (a cache miss, then a hit), in a table in the PR and in `docs/LESSONS.md`.
- It muddies one measurement: experiment [A]'s time-to-green for "Looks like a real airport". Say in `docs/LESSONS.md` from which commit the cache is in, so the real airport's numbers can be read either side of it.
- The weekly health check is being built in another session (`.github/workflows/health.yml`). Leave that file alone. If it merges first, apply the same cache there too; otherwise mention the cache in the PR so the health check can copy it.
- Branch `feature/ci-cache` from `main`, one PR. Prove it on the PR's own runs: a cache miss, then a hit (push once more, or re-run from the Actions tab).
- It may touch: `.github/workflows/checks.yml`, `.github/workflows/balance.yml`, `.github/workflows/parts.yml` (and `health.yml` only as above), the project notes' line on Playwright under "Build and test" if it changes, the steward playbook's note on the Checks workflow if it changes, a line under "The runbook" in `docs/ROADMAP.md`, `docs/LESSONS.md`, and this brief as `docs/briefs/ci-cache.md`. No change to `pages.yml` or `description.yml`.
