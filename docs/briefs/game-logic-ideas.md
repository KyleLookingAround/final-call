# Brief: Ideas to improve the game logic

The owner's brief for a ranked list of ideas to improve the game logic. No game code: ideas, not building.

## Goal and what it may touch

- Deliver a ranked list of ideas to improve Final Call's game logic (the simulation, economy, pacing, demand, passengers, managers and how choices matter), each grounded in the code and the bot, for the owner to choose from. Branch `feature/game-logic-ideas` from `main`, one PR. No game code: this is ideas, not building.
- Files it may touch: a new `docs/ideas/game-logic.md`, one-line entries under "Ideas (not agreed)" in `docs/ROADMAP.md`, this brief as `docs/briefs/game-logic-ideas.md`, and a look back in `docs/LESSONS.md`. Anything else, including `src/`, `tools/` and the specs, is outside the brief.
- What `docs/ideas/game-logic.md` holds:
  - **Where the logic is weak today**, with evidence: bot runs on `main` (seeds 1–3, `npm run bot -- 1150 --seed N`, side by side in the background) and what they show (dead stretches between levels, choices that always win, systems the bot or a player can ignore, money piling up or running dry), plus code references (`src/game/<file>:<line>`).
  - **Eight to twelve ideas**, each with: what the player would notice, the rule change in a few lines, the files and hooks it would touch (`node tools/graph.mjs`), its risk to the balance baselines and to old saves, and a rough size (small, one session; medium, a spec; large, a bundle).
  - **How they fit the owner's order of bundles** in `docs/ROADMAP.md` (especially 4, "Passengers with a voice", and 5, "A 24-hour airport with stakes"), and which existing "Ideas (not agreed)" they build on or replace.
  - **A top three** the session recommends, and why.
- Respect the owner's preferences in the project notes: no scenario choice, hide locked items, impacts shown on the map, board and gates rather than text, managers for players who don't want details, the headless simulation kept working, UK English. Nothing already rejected or parked (decor placing, a share price, eras, a sandbox, seasons, music).
