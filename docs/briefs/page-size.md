# Brief: A page size budget check

## Goal and what it may touch

- From `docs/ROADMAP.md`'s ideas: "Page size budget. A check on the size of `dist/index.html`, which grows with every feature." Add a check group that builds the page and fails if `dist/index.html` is over a budget. Set the budget at today's size (about 749 KB on `main` at 15:45 on 28 Sep) plus about 15%, rounded. On failure it prints the size, the budget, and how much each part of the page takes up (CSS, the game's script, inline images or data). Raising the budget on purpose is a one-line change in the same PR, with its reason in that PR. Branch `feature/page-size` from `main`, one PR.
- It may touch: a new `tools/checks/page-size.mjs`, a new `docs/decisions/` record for the rule, the `docs/SYSTEMS.md` checks notes (outside the `joined` markers, or its own file if the checks list is joined), a roadmap item moving the idea to done, a look back in `docs/lessons/`, and this brief as `docs/briefs/page-size.md`. No game code. It must add almost nothing to CI time: it reads a file the build already made, and doesn't start a browser.
