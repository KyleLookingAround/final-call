# Brief: Anonymous usage counts for launch week

The owner asked on 28 Sep 2026 for a way to know whether anyone came from the launch posts. The page has no analytics today.

## Goal and what it may touch

- One PR on `feature/usage-counts` from `main`: a cookie-free page counter (GoatCounter: one script tag, no cookies, no personal data, no consent banner needed) on the **published site only**, plus a few named events so the owner can see the funnel, and a switch to turn it off.
  - A constant `USAGE_SITE` (the GoatCounter site code, e.g. `finalcall`) in one place. **Empty by default:** with it empty, nothing is loaded and nothing is sent. The owner gives the code when they have it; if it arrives in the PR before merge, put it in; otherwise merging with it empty is fine and a one-line follow-up sets it.
  - Load `//gc.zgo.at/count.js` with `data-goatcounter="https://<code>.goatcounter.com/count"` only when: the code is set, the page is on the published site (reuse `feedbackRepo()`'s test in `17-help-keys-speed.js` rather than a new one), not `R.sim`, and the player hasn't turned it off. Never in `build/test.html`, never in the headless sim, never on localhost.
  - Events, each sent once per save through `window.goatcounter.count({path:'event/<name>', event:true})` and skipped when the script isn't loaded: `first-flight` (the first departure), `level-1`, `level-3`, `day-2` (the second game day begins), `photo` (a photo saved or shared), `share` (a save code copied). Nothing else, and never anything about the player. The event hook must be a no-op that costs nothing when counting is off, and must not touch `rnd()` or `G` beyond a `G.set` flag per event fired (one `FIELDS` line, an object).
  - Settings › Screen and sound (or wherever privacy-ish switches live today; look at how the Ko-fi link and update check are placed): "Send anonymous usage counts" switch, on by default, one line of plain text under it saying what's counted and that no cookies are set. A What's new fragment saying the same in one sentence.
  - `docs/systems/usage-counts.md` (one file, per the project notes), and a note in the README's privacy line if it has one (saves stay on the device; usage counts are anonymous and can be turned off).
- It may touch: a new `src/game/65-usage-counts.js` (the next free number; check `ls src/game`), `src/shell.html` (the Settings switch markup only), `03-state.js` (one `FIELDS` line), one-line hooks in `09-construction-levels-days.js` (level-up), `05-flights.js` or wherever the first departure is counted, `62-photo-mode.js`, `22-save.js` (the share code) and `15-panel.js` (the switch), `docs/systems/usage-counts.md`, `README.md`, a What's new fragment, and this brief as `docs/briefs/usage-counts.md`. `PLAY` and `STATE` identical on seeds 1–3 against `main` except the new field.
- The build rejects `Math.random()` outside a `// cosmetic` line and the checks reject DOM work under `R.sim`: the counter is DOM-only and must sit behind the `R.sim` guard. Add a check that with the code empty no script tag exists and no network request is made, and that with a code set on a non-published host nothing loads either.
