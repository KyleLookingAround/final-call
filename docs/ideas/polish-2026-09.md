### Ordering around "The terminal as a place"

Batches 2, 3, 4 and 6 all touch `src/shell.html`'s shared button/chip/card CSS broadly. `docs/specs/terminal-place.md` adds its own floor chip and terrace card to the same file, and its spec explicitly requires "the floor chip fits a 320 px phone" — the same class of fix these batches are making. To avoid two sessions editing the same shared CSS rules at once:
- Run batches 2, 3 and 4 **before** the terminal-place groundwork starts, so its floor chip is built against the corrected touch-target sizes rather than the current cramped ones.
- Batch 6 (overlay card consistency) touches `.hcard`/close-button styles that terminal-place doesn't need, so it can run any time; batches 1, 5, 7 and 8 don't touch shared chrome at all and are safe in any order.
- Rows 4 and 5 are systems-review territory, already ordered after terminal-place in `docs/ROADMAP.md`'s runbook.
