# The region map, looking better · 27 Sep 2026

- **Numbers:** session `session_018BWv4fSJ3dHAn96PMVRZ2T`, estimate $14. `get_session` hadn't reported a cost yet when the PR was opened, and the rate limit read `allowed_warning`. Started 21:04 UTC and opened the PR at 21:57. Most of that time went on screenshots, three rounds of look-and-fix, and the speed work.
- **Went well:**
  - Looking first paid off. The before screenshots (a throwaway `build/rshots.mjs` covering saves, sizes, hours, zoom and weather) named the handful of problems worth fixing, and the same script gave every round's after shots.
  - Composing the before and after pairs side by side in a Playwright page gave the PR one image per case without adding a tool.
- **Lessons:**
  - **Measure before assuming a cache is cheap.** The first cut stamped the cached land with smoothing on and was 10–20% slower than `main` on a desktop. Timing the frame with each layer switched off, one at a time, showed the scaled stamp was the cost. Two changes fixed it:
    - stamping without smoothing
    - painting at the whole-region view's own scale
    
    After those it was 8–11% quicker than `main`.
    
    Headless timings vary by about ±1 ms, so use the median of three back to back, not a single run.
  - **A cache has a rebuild cost as well as a stamp cost.** Repainting the land at a high zoom took 180 ms on a desktop, most of it large gradients. Two changes cut it to 75 ms:
    - painting the soft ground once a season at low scale
    - waiting until the zoom settles before repainting
    
    Time the rebuild as well as the frame.
  - **Nudging labels into view needs a rule about the anchor.** Clamping labels inside the view pulled an off-screen town's name to the edge, where it named the wrong place. A label is now drawn only when its place's anchor is on screen.
  - **A comment on the same line can end code.** A `//` comment added after `}` in a one-line `try` swallowed the `catch` on the next line in the check, and the whole group failed to parse. Run the group after every edit to a check.
  - Refactor 8 merged while this PR was open. The only conflict was the line-label line that read `R.fx.why`, and the new check needed `weather.set` in place of `R.fx`. The brief had warned about this, so it took one merge.
  - `create_pull_request` still appended the "Generated by" footer, so the brief's read-back-and-strip step was needed again.
