# The terminal as a place: groundwork, with refactor 9 · 28 Sep 2026

- **Numbers:** estimate $18; about $7.40 at the PR's first stopping point. Started 20:40 on 27 Sep, paused by the account's five-hour limit from about 22:20 until the coordinator woke it at 04:05; PR #113 opened at 04:22.
- **Refactor 9 went cleanly because of a pixel test written first.** A throwaway Playwright script drew 24 fixed frames (layouts, day and night, zooms, halls and roof, desktop and phone) with `performance.now` pinned, and hashed each: the move of `draw()`'s blocks into layers was pixel-identical to `main` on the first try, and the same script's roof-only diff then caught the one real slip of the groundwork (the bag tugs on the apron were drawn inside the baggage hall's `TERM_DRAW`, so gating it under the roof hid them). → Any drawing refactor meant to leave the picture as it is should start with a frame-hash script like `build/pix.mjs`; it costs minutes and settles the question.
- **`LAYER` had to move earlier.** Files before `50-scene.js` (04, 07, 12, 28) couldn't register while it was defined there (a `const` isn't reachable before its line runs); it lives in `01-constants.js` now. Within a layer, entries run in file order, so where a block registers decides what it overdraws: the terminal's tubes, links and banners register from `42` after `drawTerminal` for that reason.
- **Speed: measure against `main` alternately, not one after the other.** Two rounds of three gave 0.07× and then 0.03× for the same code, because the machine's load changed between rounds; runs taken side by side with `main` are the only fair comparison, and frame milliseconds are steadier than the calibration ratio. Batching every passenger into one path per look cut the zoomed-out scene sharply but made the zoomed-in scene slower (the canvas draws a lone circle faster than a big path when the circles are large), so dots batch only below zoom 0.6.
- **Pending checks that pass must be switched on even if they belong to a later part.** Giving every layout its own copy of the plan made three floor-plans checks pass (the way through, two hours in every layout, old saves); the pending mechanism rightly failed the run until they came out. They're guards now. [D] (c): one pre-written check's message had an operator-precedence slip (it printed "no term table" on a pass); fixed without changing its pass mark.
- **Merging `main`:** photo mode had changed `sceneView` and `darkness()` to read `drawnHour()`, and the weather refactor added `weather.on`; both folded in, and the strike pickets now read `weather.on('strike')`.
