# What else the runbook could build to earn, proposed (#136) · 28 Sep 2026

- **Numbers:** one session for two briefs (this and #135), estimate $5 each; the cost isn't reported yet when the PR opened. Two research helpers on the cheaper model, two review helpers. Docs only, no bot run.
- **Went well:** the runbook pack already existed (`npm run pack`), so the recommended option's first week is mostly copying and writing, and its appendices could be drafted from the pack's own README and brief template.
- **Lessons:**
  - The honest finding was that no option earns quickly; writing that first, before the options, kept the proposal from reading as a pitch. A brief that asks for "quickly" should expect the answer "not really" and say what it wants instead (cheapest to try, least owner time), which this one did.
  - The fresh review caught an unsourced "130 PRs in a week" and a cost range that left out the two docs-only audits over $15. Numbers quoted from the lessons need the lesson's file name beside them, which the appendix notes now require of the guide. → No change here: the rule lives in the new repo's notes (Appendix A).
