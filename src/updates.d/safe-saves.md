# Saves you can trust

- **A steady welcome back.** Time away pays a share of a typical hour’s profit, the same however often you reload.
- **No more lost airports.** Another tab or an old copy of the game can’t save over it.
- **Never frozen.** If something goes wrong, the game pauses and says so.

History: Saves can no longer be lost or frozen: a save that fails to load is kept, a second tab or older page never saves over a newer airport, a full storage says so, an error pauses the game instead of freezing it, and the welcome-back bonus no longer snowballs with each reload.
